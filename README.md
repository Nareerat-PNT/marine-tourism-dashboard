# 🚢 Dashboard สถิติการเดินเรือท่องเที่ยวทางทะเล ประจำปี 2568

เว็บ Dashboard วิเคราะห์ข้อมูลสถิติจำนวนเที่ยวเรือ ผู้โดยสาร และขนาดเรือ ของเรือโดยสารท่องเที่ยวบริเวณทะเล จำแนกตามท่าเรือของแต่ละจังหวัดในประเทศไทย (19 จังหวัด)

---

## 🌟 ฟีเจอร์ของแดชบอร์ด (Features)
- **สรุปภาพรวม (KPI Cards):** ยอดรวมผู้โดยสาร (43.3M), เที่ยวเรือรวม (1.12M), ค่าเฉลี่ยผู้โดยสารต่อเที่ยว และสถิติจังหวัดยอดนิยม
- **กราฟสรุปข้อมูล (Interactive Charts):**
  - กราฟแท่งเปรียบเทียบจำนวนผู้โดยสาร/เที่ยวเรือ รายจังหวัด
  - กราฟวงกลมแสดงสัดส่วนตามประเภทและขนาดเรือ (เรือขนาดเล็ก, เรือขนาดใหญ่, แพขนานยนต์)
  - กราฟ 10 อันดับท่าเรือที่มีผู้โดยสารหนาแน่นที่สุดในประเทศ
- **ระบบค้นหาและตัวกรอง (Filters & Search):** กรองตามจังหวัด, ขนาดเรือ หรือค้นหาตามชื่อท่าเรือ/เส้นทางเดินเรือแบบเรียลไทม์
- **ตารางข้อมูลรายละเอียด (Interactive Table):** สามารถคลิกหัวตารางเพื่อจัดเรียงลำดับ (Sort) และแบ่งหน้า (Pagination)
- **ส่งออกข้อมูล (Export):** ปุ่มดาวน์โหลดไฟล์ `CSV` และ `JSON`

---

## 📁 โครงสร้างไฟล์
- `index.html` : หน้าเว็บ Dashboard แบบสมบูรณ์ (พร้อมเปิดบน GitHub Pages ทันที)
- `data.json` : ไฟล์ชุดข้อมูลดิบในรูปแบบ JSON (169 รายการ)
- `data.csv` : ไฟล์ชุดข้อมูลในรูปแบบ CSV (เปิดด้วย Excel ได้)
- `extracted_pages_30_37.pdf` : เอกสารต้นฉบับตารางสถิติ

## 🚀 วิธีนำขึ้น GitHub เพื่อแสดงผลเป็นหน้าเว็บ (GitHub Pages)

1. เข้าเว็บ [GitHub.com](https://github.com/) และคลิก **New repository**
2. ตั้งชื่อ เช่น `marine-tourism-dashboard` และเลือกสถานะเป็น **Public**
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ Repository
4. ไปที่แท็บ **Settings** > เมนูด้านซ้ายเลือก **Pages**
5. ในส่วน **Build and deployment > Branch** เลือก `main` หรือ `master` โฟลเดอร์ `/(root)` แล้วกด **Save**
6. รอประมาณ 1-2 นาที คุณจะได้ลิงก์หน้าเว็บพร้อมใช้งานทันที เช่น:
   `https://<your-username>.github.io/marine-tourism-dashboard/`
